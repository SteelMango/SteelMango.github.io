## First off, What is a Web Fuzzer, Why is it Relevant and other alternatives?
A Fuzzer is like a dog and a tunnel. You tell the dog to search the tunnel and the dog comes back showing you the possible entrances the tunnel leads to but not only just where entrances are but what type of entrances they are made out of like wood, rock and stone.

 Cyber security wise, these entrances are hidden websites that the website owner didn't intend to leave open for the publics eyes. A snooping attacker would try to exploit these open websites and lateraly move through the system. This introfuvrd why Web Fuzzing becomes important. Businesses want to find these vulnerable websites before an actual attacker manages to find it, if they find these openings, an attacker damage assets, leak personal information or manage to get administration privilages (having the capability to control the whole system.)

Fuzzers are categorised into two ways of using input (the words that help find the website): Mutation and Generative Based Fuzzing.
Think of mutation based fuzzing like Bruce Banner, he is still human but when he transforms into the hulk, part of him is still resemble his human self except being a bit green.

**For Example:**
    normal word = apple
    mutated word = a55le

Generative Based Fuzzing takes a different approach to making 'words', instead on relying on a exising word to alter, it creates it's own version of input by following rules. If a website for example only uses dates for its 'words' then the generative fuzzer would generate things like ...

**For Example:**
    21/09/2004  (DD/MM/YY)
    99/18/9999  (DD/MM/YY)  But this date is can not be possible... and thats good because it tests for validation logic (does the website check if the information/date that was entered actually true)

# Project Glyphid

The Web Fuzzer I coded is called Glyphid, a mutation based fuzzer, programmed in Python3, does all that. Glyphid takes a web address and the user inserts the keyword FUZZ. Where FUZZ is  planted is where the fuzzer would guess the vulnerable websites by going through a wordlist, if something has been found, it records back the successful hits.

# Testing 
To find out if my tool is any good, I tested it against Ffuf; Ffuf is a open source fuzzer that is written in GO, professionally used in the Cyber Security scene.  If you want to read more about Ffuf, click [here](https://github.com/ffuf/ffuf).
