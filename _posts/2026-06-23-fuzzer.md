## First off, What is a Web Fuzzer and Why is it Relevant?
A Fuzzer is like a dog and a tunnel. You tell the dog to search the tunnel and the dog comes back showing you the possible entrances the tunnel leads to but not only just the where the entrances are but what type of entrances they are made out of like wood, rock and stone.

 Cyber security wise, these entrances are hidden websites that the website owner didn't intend to leave open for the publics eyes or a snooping attacker thats trying to lateraly move through the system. Web Fuzzing becomes important as businesses want to find these vulnerable websites before an actual attacker manages to find it. 

![Results from Glyphid](/assets/images/results1.png)

(Image above is Glyphid running a test on a website.)

My Web Fuzzer is called Glyphid, programmed in Python3, does all that. Glyphid takes a web address with the word FUZZ planted where the fuzzer would guess the vulnerable websites by going through a wordlist, then it records back the successful hits.

# Testing 
To find out if my tool is any good, I tested it against Ffuf; Ffuf is a open source fuzzer that is written in GO, professionally used in the Cyber Security scene.  If you want to read more about Ffuf, click (https://github.com/ffuf/ffuf)
