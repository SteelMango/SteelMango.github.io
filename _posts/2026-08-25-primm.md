If you are new to programming or a developer learning a new language, it's best to go over code that is written by those who are experienced than you are. PRIMM is a technique that is commonly used in computer science education for k12. Yet we can use PRIMM for our own learning for code comprehension. It solves the problem of throwing you into the deep end by hand holding you to a given schema (A schema is knowledge based around the code from personal previous experiences) and reducing cognitive load (To think of cognitive load, imagine a time you was learning a new skill, there is so much to focus on but once you continue learning that skill, you don't need to worry about the finer details since it clicks to you). With reduced cognitive load, you can focus on learning the important stuff.
