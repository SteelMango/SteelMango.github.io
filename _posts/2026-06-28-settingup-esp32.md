Apparently people still don't know this but there are better IDEs than Arduino IDE. If you're experienced in some sort of coding, Visual Studio Code has come across to you. When you read tutorials and documentation about ESP32 coding, usually you'll see Arduino IDE. But Arduino IDEs user interface looks clunky, outdated and only allows you to code for embedded devices. In this post i'll explain how to use Visual Studio Code for coding your Arduino/ESP32 and to customise the UI.
